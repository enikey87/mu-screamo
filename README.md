# Протокол

Бынич записывает мычание в протокол. Кричать можно две секунды: в справку попадает только длинное «мууу». Картинку протокола сохраняют и пересылают.

Концепт: [CONCEPT.md](CONCEPT.md).

```bash
npm install
npm test
npm run dev
```

`?card=1` открывает лист без микрофона.

Сборка публикуется на GitHub Pages с `main`: https://enikey87.github.io/mu-screamo/

Правила раунда живут в `src/core` и не знают про страницу. Фразы, длины окон и дыхание дня меняются там, `npm test` проверяет лестницу без микрофона.
