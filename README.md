# Битва с Быничем

Два режима перетягивания шкалы с Быничем: дуэль дня и чемпионат луга из пяти встреч. Он тянет, пока мычит. Громче распознанное «мууу» — сильнее тяга; хрип и перегруз тоже считаются. Перед отсчётом монетка выбирает первый ход. Полоска вдоха показывает, когда Бынич снова замычит. Край шкалы — досрочный нокаут, иначе результат определяется через восемь секунд.

На десктопе игровая сцена расширяется до 1040 px, быки и подсказки увеличиваются. На телефоне остаётся экран во всю ширину. На странице — выбор режима, бой и нужные подсказки; сообщения о микрофоне появляются только для управления без голоса или совета надеть наушники.

Концепт: [CONCEPT.md](CONCEPT.md).

```bash
npm install
npm test
npm run dev
```

Сборка публикуется на GitHub Pages с `main`: https://enikey87.github.io/mu-screamo/

Правила раунда живут в `src/core` и не знают про страницу. Длины окон и дыхание дня меняются там, `npm test` проверяет их без микрофона.

Проверки:

```bash
npm test
npm run build
npm run test:browser
```

Браузерные проверки собирают production-версию и запускают её через Vite Preview в headless Google Chrome: проверяют вёрстку, отказ в микрофоне, управление удержанием, результаты, повторный раунд и освобождение микрофона. Chrome должен быть установлен; другой путь к исполняемому файлу можно передать через `CHROME_BIN`. Снимки экранов сохраняются во временную папку, путь выводится в конце проверки.

В чемпионате Бынич с каждой встречей свирепеет, а игрок распределяет запас воздуха между его вдохами. Победы открывают следующие встречи, прогресс сохраняется в браузере. [Открыть чемпионат](https://enikey87.github.io/mu-screamo/#championship).

Атлас чемпионата: `public/art/bull-championship-isolated.webp` — четыре ступени свирепости, два состояния каждой морды; первая встреча использует прежний рисунок. Получен встроенным `image_gen` по исходным цветным быкам, затем сохранён в WebP с прозрачностью. Между кадрами оставлены прозрачные отступы, чтобы соседний спрайт не попадал в сцену. [Промпты и кадрирование](public/art/bull-championship-isolated.prompt.txt).

Фоны чемпионата: [у изгороди](public/art/arena-fence.webp), [во дворе](public/art/arena-yard.webp), [вечерний луг](public/art/arena-evening.webp). Получены встроенным `image_gen`, сохранены в WebP 1200×800. [Промпты](public/art/arena-locations.prompt.txt).

Микрофон запрашивает браузерное эхоподавление, без автогромкости и подавления шума. Звук игры проходит через локальный WebRTC, чтобы попасть в опорный сигнал эхоподавителя; голос игрока туда не передаётся. Если браузер не подтверждает эхоподавление, игра советует наушники. Реальную акустику колонок и комнаты автоматические проверки не воспроизводят. [Устройство голоса и ограничения проверки](docs/moo-synthesis.md).
