# Битва с Быничем

Деревенский чемпионат: перетягивание шкалы с Быничем. Он тянет, пока мычит. Шкала едет от «мууу», не от крика.

Концепт: [CONCEPT.md](CONCEPT.md).

```bash
npm install
npm test
npm run dev
```

Сборка публикуется на GitHub Pages с `main`: https://enikey87.github.io/mu-screamo/

Правила раунда живут в `src/core` и не знают про страницу. Длины окон и дыхание дня меняются там, `npm test` проверяет их без микрофона.

Проверки:

```bash
npm test
npm run build
npm run test:browser
```

Браузерные проверки запускают локальный Vite и headless Google Chrome: проверяют вёрстку, отказ в микрофоне, управление удержанием, результаты, повторный раунд и освобождение микрофона. Chrome должен быть установлен; другой путь к исполняемому файлу можно передать через `CHROME_BIN`. Снимки экранов сохраняются во временную папку, путь выводится в конце проверки.
