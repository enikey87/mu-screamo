# Битва с Быничем

Браузерная голосовая дуэль: мычи «му-у-у» в микрофон, лови вдохи Бынича и перетягивай шкалу на свою сторону.

**[Играть](https://enikey87.github.io/mu-screamo/)** · **[Чемпионат луга](https://enikey87.github.io/mu-screamo/#championship)**

## Как играть

1. Выбери режим, прими вызов и разреши микрофон. Монетка покажет, кто мычит первым.
2. Дождись отсчёта 4–3–2–1 с шагом в секунду и полной секундой после «1» перед стартовым сигналом. На команде **«МЫЧИ»** тяни низкое «му-у-у». Таймер и убывающая зелёная полоска над твоим быком показывают, сколько ещё держать голос. **«Держи!»** подтверждает распознанное «му»; **«ПАУЗА»** предлагает остановиться и набрать воздух. Команда **«ЖДИ»** предупреждает о следующем окне. Крупная команда находится между быками. Над Быничем заполняется шкала вдоха и идёт отсчёт до его голоса; за полсекунды она краснеет, во время мычания показывает «МУ-У», после последнего вдоха — прочерк.
3. Громче распознанное «му» — сильнее тяга. Хрип и перегруз тоже учитываются; «ааа», свист и шум шкалу не тянут. Чем сильнее мычание, тем сильнее дрожит соперник.
4. Дотащи маркер до чужого края для нокаута. Иначе после восьми секунд боя побеждает тот, кто перетянул шкалу; у середины — ничья.

Зелёная доля шкалы — твоя, красная — Бынича. Можно мычать и поверх его голоса, но на вдохе это эффективнее.

## Режимы

- **Дуэль дня.** Базовый рисунок дыхания и высота голоса меняются с местной датой. Монетка выбирает начальную фазу; ограничения запаса воздуха нет.
- **Чемпионат луга.** Пять встреч: Разминка → Упрямство → Вызов → Ярость → Финал. У каждого соперника три ритма: перед раундом выбирается один, без повторения предыдущего рисунка этого соперника внутри сессии. Разминка сохраняет длинные окна, финал ускоряется к концу. Выбранный ритм не меняется во время боя — звук и индикаторы следуют одной последовательности. Бынич свирепеет, мычит громче и грубее; твой запас воздуха уменьшается. Таймер команды учитывает оставшийся воздух. Молчи между фразами, чтобы восстановить его. При истощении тяга прекращается до восстановления 40% запаса.

Победы открывают следующие встречи. Кнопка «Следующая встреча» сразу запускает новый раунд; после финала так же можно сразу начать чемпионат заново. Пройденные встречи можно выбрать для повторной игры. Прогресс чемпионата сохраняется в браузере на этом устройстве. Путь виден по сцене: у изгороди → во дворе → на вечернем лугу.

## Микрофон и устройства

Голос обрабатывается локально: записи и отправки голоса нет. Микрофон включается на раунд и освобождается после него или при смене режима. Игра запрашивает браузерное эхоподавление; если его работа не подтверждена, появляется совет надеть наушники. Подробности: [устройство звука и ограничения эхоподавления](docs/moo-synthesis.md).

Если микрофон недоступен или в разрешении отказано, появляется кнопка **«Зажми и тяни»**. Удерживай её вместо мычания; в чемпионате отпускай для восстановления воздуха. На клавиатуре можно удерживать пробел или Enter, когда кнопка в фокусе.

Оба режима оформлены как деревенская панк-афиша: бумага, тёмная печать, терракотовые акценты и цветные быки. На десктопе сцена расширяется до 1200 px, на телефоне занимает всю ширину. Режим уменьшенного движения отключает анимации, сохраняя команды, шкалы и таймер игрока.

Мобильная вёрстка проверена в Chrome с узкими размерами окна, включая ширину 280–390 px. На физических iPhone и Android микрофон и эхоподавление пока не проверены; автоматические проверки не воспроизводят акустику реальной комнаты.

## Локальный запуск

Нужны **Node.js 24+** и npm.

```bash
npm ci
npm run dev
```

Открой адрес, который выведет Vite. Для production-сборки и её просмотра:

```bash
npm run build
npm run preview
```

Результат сборки — `dist/`. Из `main` GitHub Actions запускает тесты и сборку, затем публикует игру на GitHub Pages. Для PR выполняется проверка без публикации.

## Проверки

```bash
npm test
npm run typecheck
npm run build
npm run test:browser
```

`npm test` проверяет распознавание синтетических гласных, силу голоса, правила раунда, нокауты, дыхание, выбор первого хода, ритмы и прогресс чемпионата. Эти проверки не требуют микрофона.

`npm run test:browser` собирает игру и запускает её через Vite Preview в headless Google Chrome. Проверяет мобильную и десктопную вёрстку, кадрирование спрайтов, монетку и вдох, работу с разрешениями микрофона, управление удержанием, победы и поражения, переходы чемпионата и сохранение прогресса. Звуковые сценарии используют синтетические сигналы и тестовый микрофон Chrome. Нужен установленный Google Chrome; другой путь можно передать через `CHROME_BIN`. Скриншоты сохраняются во временную папку, путь выводится в конце проверки.

Отдельный линтер в проекте не настроен.

## Устройство проекта

- `src/core/` — распознавание «му», сила голоса, дыхание дня, правила раунда и чемпионата; без зависимостей от страницы и микрофона.
- `src/audio/` — захват микрофона, синтез голоса Бынича, отсчёт и вывод звука.
- `src/main.ts`, `src/style.css`, `index.html` — интерфейс и связь игры со звуком.
- `public/art/` — цветные быки, атлас чемпионата и фоны.
- [CONCEPT.md](CONCEPT.md) — подробные правила и границы проекта.
- [docs/moo-synthesis.md](docs/moo-synthesis.md) — синтез голоса, расщепление и эхоподавление.

## Графика

Четыре эмоции быка, атлас чемпионата и три фона перерисованы встроенным `image_gen` в стиле грубой цветной печати и сохранены в WebP. Атлас содержит четыре ступени свирепости с двумя состояниями каждой морды; первая встреча использует основного быка. Прозрачные отступы отделяют соседние кадры.

Шрифт Oswald с кириллицей хранится локально в `public/fonts/`; внешних запросов к сервисам шрифтов нет. Источник — [Google Fonts](https://github.com/google/fonts/tree/main/ofl/oswald), лицензия — [SIL OFL](public/fonts/OFL.txt). При недоступном шрифте остаётся системный.

Промпты, пути ресурсов и кадрирование: [деревенский панк](public/art/punk.prompt.txt).
