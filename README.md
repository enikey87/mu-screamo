# Битва с Быничем

Два режима перетягивания шкалы с Быничем: дуэль дня и чемпионат луга из пяти встреч. Он тянет, пока мычит. Шкалу тянет «мууу», включая хриплое и перегруженное.

Концепт: [CONCEPT.md](CONCEPT.md).

```bash
npm install
npm test
npm run dev
```

Сборка публикуется на GitHub Pages с `main`: https://enikey87.github.io/mu-screamo/

Правила раунда живут в `src/core` и не знают про страницу. Длины окон и дыхание дня меняются там, `npm test` проверяет их без микрофона.

Проверки:

```bash
npm test
npm run build
npm run test:browser
```

Браузерные проверки собирают production-версию и запускают её через Vite Preview в headless Google Chrome: проверяют вёрстку, отказ в микрофоне, управление удержанием, результаты, повторный раунд и освобождение микрофона. Chrome должен быть установлен; другой путь к исполняемому файлу можно передать через `CHROME_BIN`. Снимки экранов сохраняются во временную папку, путь выводится в конце проверки.

В чемпионате Бынич с каждой встречей свирепеет, а игрок распределяет запас воздуха между его вдохами. Победы открывают следующие встречи, прогресс сохраняется в браузере. [Открыть чемпионат](https://enikey87.github.io/mu-screamo/#championship).

Новый арт: `public/art/bull-championship.webp` — четыре ступени свирепости, два состояния каждой морды; первая встреча использует прежний рисунок. Получен встроенным `image_gen` по исходным цветным быкам, затем сохранён в WebP с прозрачностью. Промпты: `public/art/bull-championship.prompt.txt`.

Фоны чемпионата: [у изгороди](public/art/arena-fence.webp), [во дворе](public/art/arena-yard.webp), [вечерний луг](public/art/arena-evening.webp). Получены встроенным `image_gen`, сохранены в WebP 1200×800. [Промпты](public/art/arena-locations.prompt.txt).
